# سایت پارسیان — راهنمای استفاده

این پوشه یک سایت کامل چندصفحه‌ای با پنل مدیریت محتوا (CMS) است که بدون نیاز به سرور پیچیده کار می‌کند (گزینه A).

## ساختار فایل‌ها

```
website/
├── index.html          صفحه خانه
├── about.html          درباره ما
├── products.html       لیست محصولات
├── product.html        جزئیات هر محصول (با ?id=...)
├── services.html       خدمات پس از فروش
├── news.html           لیست اخبار
├── news-article.html   جزئیات هر خبر (با ?id=...)
├── gallery.html        گالری
├── contact.html        تماس با ما
├── admin.html          ⭐ پنل مدیریت (ورود با رمز)
├── data.json           ⭐ قلب سایت — تمام محتوا اینجاست
└── assets/
    ├── css/style.css   استایل مشترک همه صفحات
    └── js/
        ├── common.js   هدر، فوتر، تغییر زبان
        ├── site.js     ساخت محتوای صفحات از data.json
        └── admin.js    منطق پنل مدیریت
```

## چطور سایت را روی کامپیوتر خودم ببینم؟

به‌دلیل امنیت مرورگرها، فایل `data.json` فقط وقتی بارگذاری می‌شود که سایت از طریق یک «سرور محلی» باز شود (نه با دابل‌کلیک مستقیم روی فایل).

ساده‌ترین راه‌ها:

**روش ۱ — با پایتون (اگر نصب است):**
ترمینال را در پوشه `website` باز کنید و این را اجرا کنید:
```
python -m http.server 8000
```
سپس در مرورگر بروید به: `http://localhost:8000`

**روش ۲ — با افزونه VS Code:**
افزونه «Live Server» را نصب کنید، روی `index.html` راست‌کلیک کنید و «Open with Live Server» را بزنید.

**روش ۳ — با Node (اگر نصب است):**
```
npx serve
```

## پنل مدیریت چطور کار می‌کند؟

۱. به `admin.html` بروید (یا از فوتر/نوار بالای سایت روی «ورود مدیر» کلیک کنید).
۲. رمز عبور را وارد کنید. رمز پیش‌فرض: **parsian1381**
   - ⚠️ حتماً این رمز را در فایل `assets/js/admin.js` (خط `password:`) تغییر دهید.
۳. از منوی راست بخش مورد نظر را انتخاب کنید: اخبار، محصولات، خدمات، گالری، درباره ما، تماس.
۴. تغییرات را بزنید و «ذخیره» کنید. تغییرات بلافاصله روی سایت (در همین مرورگر) اعمال می‌شود.

### افزودن یک خبر جدید (مثلاً بعد از نمایشگاه)
بخش «اخبار» → «خبر جدید» → عنوان، تاریخ، دسته (نمایشگاه/فناوری/...)، خلاصه، متن و عکس را وارد کنید → «ذخیره خبر».

## مهم: چطور تغییرات روی سایت واقعی (اینترنت) منتشر شوند؟

در این روش (گزینه A بدون سرور بک‌اند)، تغییراتی که در پنل می‌دهید **ابتدا فقط در مرورگر خودتان** ذخیره می‌شوند. برای انتشار روی سایت واقعی:

۱. در پنل، روی دکمه نارنجی **«⬇ دانلود data.json (انتشار)»** بزنید.
۲. فایل `data.json` دانلود می‌شود.
۳. این فایل را روی هاست خود **جایگزین** فایل `data.json` قبلی کنید (از طریق FTP یا کنترل‌پنل هاست).
۴. تمام! سایت برای همه بازدیدکنندگان به‌روز می‌شود.

> این یعنی مسئول سایت فقط باید بلد باشد یک فایل را روی هاست آپلود کند. اگر این مرحله هم برایتان دست‌وپاگیر است، می‌توانیم بعداً به «گزینه B» (Strapi) ارتقا دهیم که انتشار کاملاً خودکار است.

## آپلود روی هاست
کل پوشه `website` را روی هاست خود آپلود کنید (پارس‌پک، آروان، یا هر هاست دیگر). فایل `index.html` صفحه اصلی خواهد بود.

## دو زبانه (فارسی / انگلیسی)
با دکمه FA/EN در نوار بالای سایت زبان عوض می‌شود. تمام محتوا در `data.json` دو نسخه دارد (مثلاً `titleFa` و `titleEn`). در پنل هم هر دو فیلد را می‌بینید.

## مرحله بعد
این ساختار کلی است. حالا می‌توانیم با هم جزئیات هر صفحه را دقیق‌تر کنیم: متن‌ها، عکس‌ها، رنگ‌ها، فیلدهای بیشتر برای محصولات، و هر چیزی که لازم باشد.
